# Issue Tracker

A full-stack issue-tracking application with a React/Vite frontend and Python backend.

## Usage

Install frontend dependencies in `frontend` with `npm ci`, then use `npm run dev` or `npm run build`. Install backend dependencies into a virtual environment with `python -m pip install -r backend/requirements.txt`; review the backend entry point and database configuration before starting it.
